# Guide 03: Write or Edit a Blog Post

**Use this when:** you want to publish a new article, or edit an existing one, on the Intervention Blog.

## Where to go

1. Log in: **https://interventiodev.wpenginepowered.com/wp-admin/**
2. In the left menu, click **Posts**.
3. Direct link (all posts): **https://interventiodev.wpenginepowered.com/wp-admin/edit.php**
4. To start a new one: **Posts**, then **Add New**, or **https://interventiodev.wpenginepowered.com/wp-admin/post-new.php**

## Steps to write a new post

1. Type the article **Title** at the top.
2. Write the article in the main area. Add headings, paragraphs, images, and links as normal.
3. On the right, set a **Featured Image**. This is the thumbnail shown on the blog list. Look for the "Featured image" box and click "Set featured image."
4. (Optional) Write a short **Excerpt** on the right. This is the summary shown on the blog list under the title.
5. Click the blue **Publish** button.

## Steps to edit an existing post

1. Go to **Posts**.
2. Search for the article, hover over it, click **Edit**.
3. Make your changes.
4. Click **Update**.

## Where it appears

- The article gets its own page at `https://intervention.com/intervention-blog/your-article-name`
- It also shows up automatically in the blog list at `https://intervention.com/intervention-blog`

## When will I see it on the live site?

About 1 minute for both the article and the blog list. Refresh the live blog page to confirm.

## Tip

Always set a Featured Image. Articles without one look empty in the blog list.
