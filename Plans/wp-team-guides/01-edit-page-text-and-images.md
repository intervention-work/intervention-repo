# Guide 01: Edit the Words or Images on an Existing Page

**Use this when:** you want to fix a typo, change a sentence, or swap a picture on a page that already exists (for example the About page, a state page, or the Insurance page).

## Where to go

1. Log in: **https://interventiodev.wpenginepowered.com/wp-admin/**
2. In the left menu, click **Pages**.
3. Direct link: **https://interventiodev.wpenginepowered.com/wp-admin/edit.php?post_type=page**

## Steps

1. In the list of pages, find the page you want. You can type its name in the search box at the top right.
2. Hover over the page name and click **Edit**.
3. Change the text directly, just like typing in a document.
4. To replace an image: click the image, click the small pencil or "Replace" icon, then choose a new image from the media library or upload one.
5. When you are done, click the blue **Update** button (top right).

## When will I see it on the live site?

About 1 minute. Open the live page in your browser and refresh (press the refresh button or F5). Your change is there.

## Tips

- Change one thing, save, and check the live site. This makes it easy to see the effect.
- If you paste text from Microsoft Word, use the "Paste as plain text" option if available, so odd formatting does not come along.
- You cannot break the page design. The website automatically wraps your words in the correct fonts, colors, and spacing.

## Watch out

- Do not change the page's "Permalink" (its web address) unless you really mean to. Changing it can break links that point to the page. See Guide 07 if you must.
