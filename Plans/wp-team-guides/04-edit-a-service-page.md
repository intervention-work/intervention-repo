# Guide 04: Edit or Add a Service (Detail Page)

**Use this when:** you want to change one of the services (for example Drug Intervention, Alcohol Intervention, Senior Support Services) or add a brand new service.

Services are special. They live in their own section called **Detail Pages**, not under normal Pages.

## Where to go

1. Log in: **https://interventiodev.wpenginepowered.com/wp-admin/**
2. In the left menu, click **Detail Pages**.
3. Direct link: **https://interventiodev.wpenginepowered.com/wp-admin/edit.php?post_type=detail_page**

## The fields you will see (and what they do)

When you open a Detail Page, you will see labeled boxes. Here is what each one controls on the live site:

| Field | What it controls |
|---|---|
| **Title (H1)** | The big heading at the top of the service page |
| **Label (nav / card text)** | The short name shown in the menu and on service cards |
| **Summary** | The sentence under the heading, and the Google description |
| **Intro paragraph** | The opening line of the page body |
| **Hero Image** | The background photo at the top of the page |
| **Eyebrow** | The small text above the heading (optional) |
| **Parent Section** | Whether it belongs under Intervention or Services |
| **Slug** | The last part of the web address |
| **Order** (Page Attributes box) | The position in the menu and card grid (smaller number = higher up) |

## Steps to edit an existing service

1. Go to **Detail Pages**.
2. Click the service you want to edit.
3. Change the fields you need (for example update the Summary or replace the Hero Image).
4. Click the blue **Update** button.

## Steps to add a new service

1. Go to **Detail Pages**, then **Add New**.
2. Fill in the Title, Label, Summary, and Intro.
3. Choose the **Parent Section** (Intervention or Services).
4. Set the **Slug** (for example `grief-support`).
5. Set a **Hero Image** if you want one.
6. Set the **Order** number in the Page Attributes box to control where it sits in the list.
7. Click **Publish**.

## When will I see it on the live site?

About 1 minute. Both the service page itself and the section landing page (Intervention or Services) update together.

## Important note about the top background photo

All Intervention service pages share one background photo, and all Services pages share another. This is on purpose, for a consistent look. If you change the Hero Image on the reference service, the others follow. If you are unsure, ask the developer before changing hero photos in bulk.

## Reminder

A new service does NOT automatically appear in the top menu. To add it to the menu, see Guide 05.
