# Guide 02: Add a Brand New Page

**Use this when:** you want to create a page that does not exist yet (for example a new city page, a new information page, or a new landing page).

## Where to go

1. Log in: **https://interventiodev.wpenginepowered.com/wp-admin/**
2. In the left menu, click **Pages**, then **Add New**.
3. Direct link: **https://interventiodev.wpenginepowered.com/wp-admin/post-new.php?post_type=page**

## Steps

1. Type the page **Title** at the top. This becomes the big heading on the page.
2. Write your content in the main area below. Use headings, bullet points, and paragraphs as normal.
3. Add images where you want them.
4. (Optional but recommended) On the right side, set a short **Excerpt** if you see that box. This becomes the page's description in Google search results.
5. Click the blue **Publish** button (top right). Confirm by clicking **Publish** again if it asks.

## The web address of your new page

WordPress creates the address from the title. For example, a page titled "Intervention in Dallas" becomes:

`https://intervention.com/intervention-in-dallas`

You can see and adjust this address in the **Permalink** box (usually near the top or in the right sidebar) before publishing.

## When will I see it on the live site?

The very first time someone opens the new web address, the live site builds it and shows it. So:

1. Publish in WordPress.
2. Open the new page's address in your browser.
3. It appears. (The first open can take a couple of seconds. After that it is instant for everyone.)

## Important: linking to your new page

A new page does NOT automatically appear in the top menu. If you want people to reach it from the menu, add it there. See Guide 05 (Navigation Menu).

You can also link to it from inside other pages using a normal text link.
